# Delivery roadmap

## Phase 1 — MVP

- Peer discovery list
- 1:1 text messaging
- Single-file transfer with progress bar
- Basic modern chat UI

## Phase 2 — Reliability and performance

- Multi-file/folder transfer
- Resume interrupted transfers
- Parallel chunk streaming
- Hash-based integrity verification

## Phase 3 — UX polish

- Search, pinned peers, quick actions
- Notifications + focus mode
- Accessibility and keyboard shortcuts

## Phase 4 — Security + enterprise readiness

- Contact verification workflows
- Optional room-level E2E encryption
- Signed installers and auto-updates
